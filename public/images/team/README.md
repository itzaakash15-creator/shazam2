# Team Photos Directory

Drop your 6 team member photos here:

- `member1.jpg` (or `.png` / `.webp`)
- `member2.jpg`
- `member3.jpg`
- `member4.jpg`
- `member5.jpg`
- `member6.jpg`

Update the `image` field in `src/data/team.ts` if you use different filenames.

If a photo is not found, the website will automatically display a clean, neutral ocean-tech monogram placeholder rather than broken images or artificial faces.
