# shazam2

## Team SHAZAM — SIH26123

> **Edge AI Based Distributed Fleet Coordination for Autonomous Mobile Robots for Smart Warehouses**

A professional project website for Team SHAZAM's Smart India Hackathon 2026 solution (SIH26123).

### Features
- **Cinematic 5-AMR Simulation Canvas:** Interactive warehouse floor visualization showing multi-robot navigation, LIDAR radii, and Fast DDS peer data links.
- **Centralized vs. Distributed Comparison:** Interactive trade-off exploration between central server dispatch and edge coordination.
- **7-Step Core Flow:** SENSE → SHARE → DECIDE → PLAN → COORDINATE → MOVE → REPLAN.
- **Interactive D* Lite Sandbox:** Live obstacle injection and incremental route recalculation.
- **Conflict & Deadlock Resolution:** Intersection right-of-way arbitration and narrow aisle pocket bypassing.
- **Industrial Dashboard:** Real-time telemetry inspector for 5 AMRs, large floor schematic, and simulation event stream.
- **Technology Stack:** ROS 2, Python, Gazebo, Fast DDS, React, Raspberry Pi, D* Lite.
- **Team & Mentors:** Verified Team SHAZAM roster and mentors.

### Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Vanilla CSS + TailwindCSS v4
- **Icons:** Lucide React

### Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build production bundle
npm run build
```
